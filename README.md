# QRPay-Import plugin repo template

1. Edit `dist/manifest.json`: replace `author` and `website`.
2. Create a GitHub repo and push this folder's contents at repo root.
3. `index.txt` already contains `dist`.
4. Verify raw URL:
   https://raw.githubusercontent.com/<you>/<repo>/refs/heads/main/dist/manifest.json
5. Fork AstralSightStudios/AstroBox-NG-Plugin-Repo, append:
   https://raw.githubusercontent.com/<you>/<repo>/refs/heads/main/
6. Open PR.
